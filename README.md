# Gideon's Birthday

A single-page, live-updating counter showing the days and weeks until and
since the 28th of April. Pastel theme, Poppins font, no build step required.

## Deploy to Vercel

This is a static site (just `index.html`), so Vercel needs no build
configuration — import the repo and deploy as-is, or run:

```
vercel
```

from this directory.
